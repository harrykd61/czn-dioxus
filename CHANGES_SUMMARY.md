# Сводка внесённых изменений

## ✅ Реализованные улучшения

### 1. Безопасность: Шифрование токена через Windows DPAPI
**Файлы**: `src/storage.rs`, `Cargo.toml`

- ✅ Добавлено шифрование токена через Windows Data Protection API (DPAPI)
- ✅ Токен теперь хранится в зашифрованном виде
- ✅ Добавлена поддержка fallback для не-Windows платформ
- ✅ Улучшены права доступа к файлам (ограничение доступа только для текущего пользователя)

**Изменения**:
- Добавлен feature `Win32_Security_DataProtection` в `Cargo.toml`
- Реализованы функции `encrypt_data()` и `decrypt_data()` для работы с DPAPI
- Обновлены `save_token()` и `load_token()` для использования шифрования

### 2. Асинхронность: Вынос блокирующих операций
**Файлы**: `src/main.rs`, `src/signing.rs`

- ✅ `find_certificates()` теперь выполняется в `spawn_blocking`
- ✅ Выполнение `cryptcp.exe` вынесено в отдельный поток через `spawn_blocking`
- ✅ UI больше не блокируется при долгих операциях

**Изменения**:
- Обёртка `find_certificates()` в `tokio::task::spawn_blocking`
- Обёртка `Command::output()` в `spawn_blocking` для выполнения cryptcp.exe

### 3. Поллинг: Исправление бесконечного цикла
**Файлы**: `src/main.rs`

- ✅ Заменён `use_future` с бесконечным циклом на управляемый через сигналы
- ✅ Добавлена возможность отмены поллинга через сигнал `should_poll`
- ✅ Улучшена структура кода для лучшего управления жизненным циклом

**Изменения**:
- Использование `use_future` с проверкой `should_poll()` для контроля выполнения
- Добавлена возможность остановки поллинга при необходимости

### 4. Mutex: Устранение долгой блокировки
**Файлы**: `src/dispenser.rs`

- ✅ Убрана долгая блокировка `Mutex` во время сетевых запросов
- ✅ Список задач клонируется перед выполнением async операций
- ✅ Улучшена конкурентность приложения

**Изменения**:
- В `check_all_tasks()` список задач клонируется в блоке `{}` перед await
- Mutex освобождается до выполнения сетевых запросов

### 5. HTTP: Тайм-ауты и обработка ошибок
**Файлы**: `src/dispenser.rs`, `src/signing.rs`

- ✅ Добавлены тайм-ауты для всех HTTP запросов (30 сек для запроса, 10 сек для подключения)
- ✅ Улучшена обработка ошибок сети
- ✅ Централизованная конфигурация тайм-аутов

**Изменения**:
- Все `reqwest::Client::new()` заменены на `Client::builder()` с тайм-аутами
- Использование констант из модуля `config` для тайм-аутов

### 6. UX: Улучшение отображения ошибок
**Файлы**: `src/main.rs`, `src/dispenser.rs`

- ✅ Улучшено отображение ошибок в UI с цветовой индикацией
- ✅ Использование `display_name()` для отображения названий групп товаров
- ✅ Более информативные сообщения об ошибках

**Изменения**:
- Добавлена цветовая индикация для ошибок (красный) и успешных операций (синий)
- Исправлено использование `display_name()` в результатах выгрузки задач
- Улучшена структура отображения ошибок с детализацией

### 7. Конфигурация: Вынос констант
**Файлы**: `src/config.rs` (новый), `src/dispenser.rs`, `src/signing.rs`, `src/main.rs`

- ✅ Создан модуль `config.rs` с централизованными константами
- ✅ Все жёстко закодированные значения вынесены в конфигурацию
- ✅ Упрощена настройка приложения

**Константы в config.rs**:
- `API_BASE_URL` - базовый URL API
- `PRODUCT_GROUP_CODES` - коды групп товаров
- `VIOLATION_CATEGORY` и `VIOLATION_KIND` - параметры нарушений
- `HTTP_TIMEOUT_SECS` и `HTTP_CONNECT_TIMEOUT_SECS` - тайм-ауты
- `TASK_CHECK_INTERVAL_SECS` - интервал проверки задач
- `MAX_RETRY_ATTEMPTS` - максимальное количество повторов
- И другие параметры приложения

### 8. Очистка: Управление временными файлами
**Файлы**: `src/signing.rs`

- ✅ Добавлена автоматическая очистка временных файлов через `Drop` trait
- ✅ Гарантированное удаление файлов даже при ошибках
- ✅ Использование структуры `TempFileGuard` для RAII

**Изменения**:
- Создана структура `TempFileGuard` с реализацией `Drop`
- Временные файлы автоматически удаляются при выходе из области видимости
