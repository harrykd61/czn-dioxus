# План улучшений проекта CZN-Dioxus

## Приоритет 1: Критичные проблемы безопасности и стабильности

### 1.1 Шифрование токена через Windows DPAPI
**Проблема**: Токен хранится в открытом виде в `%APPDATA%\czn-dioxus\token.dat`
**Решение**: Использовать Windows Data Protection API (DPAPI) для шифрования
**Файлы**: `src/storage.rs`
**Зависимости**: Добавить `windows-data-protection` или использовать Windows API напрямую

### 1.2 Блокирующие операции в async контексте
**Проблема**: `find_certificates()` и `Command::new().output()` блокируют async runtime
**Решение**: Вынести в `tokio::task::spawn_blocking`
**Файлы**: `src/main.rs`, `src/signing.rs`, `src/certificate.rs`

### 1.3 Бесконечный цикл без отмены
**Проблема**: `use_future` создаёт бесконечный цикл без возможности отмены
**Решение**: Использовать `use_effect` с возможностью отмены через `AbortHandle`
**Файлы**: `src/main.rs`

### 1.4 Долгая блокировка Mutex
**Проблема**: `TASKS.lock()` удерживается во время сетевых запросов
**Решение**: Клонировать список задач перед await
**Файлы**: `src/dispenser.rs`

## Приоритет 2: Улучшения надежности

### 2.1 HTTP тайм-ауты и retry логика
**Проблема**: Нет тайм-аутов, слабая обработка ошибок
**Решение**: Создать централизованный HTTP клиент с тайм-аутами
**Файлы**: `src/dispenser.rs`, `src/signing.rs`

### 2.2 Улучшенная обработка временных файлов
**Проблема**: Временные файлы могут остаться при ошибках
**Решение**: Использовать `scopeguard` или `defer`-подобную логику
**Файлы**: `src/signing.rs`

### 2.3 Улучшение прав доступа к файлам
**Проблема**: Файлы создаются с правами по умолчанию
**Решение**: Установить ограниченные права доступа (только для текущего пользователя)
**Файлы**: `src/storage.rs`

## Приоритет 3: Улучшения UX

### 3.1 Отображение ошибок в UI
**Проблема**: Ошибки только в консоли/логе
**Решение**: Добавить компонент для отображения ошибок
**Файлы**: `src/main.rs`

### 3.2 Использование display_name в результатах
**Проблема**: В результатах показывается код вместо названия
**Решение**: Использовать `TaskStatusForUI::display_name()`
**Файлы**: `src/dispenser.rs`

### 3.3 Индикатор прогресса для долгих операций
**Проблема**: Нет обратной связи при долгих операциях
**Решение**: Добавить прогресс-бары и статусы
**Файлы**: `src/main.rs`

## Приоритет 4: Конфигурация и архитектура

### 4.1 Вынос констант в конфигурацию
