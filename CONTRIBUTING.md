# Вклад в развитие czn-dioxus

Этот документ описывает, как вы можете внести свой вклад в развитие проекта czn-dioxus.

## Обзор вклада

Мы приветствуем вклад от всех желающих! Независимо от вашего опыта, вы можете помочь в развитии проекта.

### Как вы можете помочь

- **Разработка** - Написание кода, исправление багов
- **Тестирование** - Поиск и сообщение о багах
- **Документация** - Написание и улучшение документации
- **Дизайн** - Улучшение пользовательского интерфейса
- **Поддержка** - Помощь другим пользователям
- **Перевод** - Локализация приложения

## Начало работы

### 1. Подготовка окружения

#### Требования

- **Rust 1.70+**
- **Node.js 16+** (для фронтенда)
- **Git**
- **Windows SDK** (для Windows разработки)

#### Установка зависимостей

```bash
# Установка Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

# Установка Node.js
# Скачайте с https://nodejs.org/

# Установка зависимостей Rust
cargo build

# Установка frontend зависимостей
cd frontend
npm install
```

### 2. Клонирование репозитория

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/czn-dioxus.git
cd czn-dioxus

# Создание ветки для разработки
git checkout -b feature/your-feature-name
```

### 3. Запуск проекта

```bash
# Запуск backend
cargo run

# Запуск frontend (в отдельном терминале)
cd frontend
npm run dev
```

### 4. Тестирование

#### Типы тестов

- **Unit тесты** - Тестирование отдельных функций
- **Интеграционные тесты** - Тестирование взаимодействия модулей
- **End-to-end тесты** - Тестирование полного цикла
- **Тесты производительности** - Проверка производительности

#### Написание тестов

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::path::Path;
    
    #[test]
    fn test_certificate_loading() {
        // Подготовка
        let test_cert_path = "./test_data/test_cert.p12";
        
        // Действие
        let result = load_certificate(test_cert_path);
        
        // Проверка
        assert!(result.is_ok());
        let cert = result.unwrap();
        assert_eq!(cert.subject_name, "Test Certificate");
    }
    
    #[test]
    fn test_file_signing() {
        // Подготовка
        let test_file = "./test_data/test_file.txt";
        let output_file = "./test_data/test_file_signed.txt";
        let certificate = get_test_certificate();
        
        // Действие
        let result = sign_file_with_certificate(
            &certificate,
            Path::new(test_file),
            Path::new(output_file)
        );
        
        // Проверка
        assert!(result.is_ok());
        assert!(Path::new(output_file).exists());
    }
}
```

## Частые вопросы

### Q: Как начать вносить вклад?

A: Начните с простых задач:
1. Исправление опечаток в документации
2. Добавление комментариев к коду
3. Тестирование существующих функций
4. Сообщение о багах

### Q: Нужно ли быть экспертом в Rust?

A: Нет! Мы приветствуем участников всех уровней. Главное - желание учиться и помогать.

### Q: Как долго ждать ответа на PR?

A: Обычно в течение 1-2 недель. Если прошло больше времени - напишите напоминание.

### Q: Можно ли работать над несколькими задачами одновременно?

A: Да, но лучше фокусироваться на одной задаче за раз для лучшего качества.
